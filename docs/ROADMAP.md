# Roadmap

## Expansion point — server-backed accounts

- Status: expansion point
- Origin: the current README and page implementations explicitly use browser
  local storage and no login or database.
- Decision: keep data local until account, privacy, and synchronization needs
  are defined.
- Blocked on: product requirements for accounts, data ownership, and hosting.
- Touch-list sketch: storage module, authentication, API/database layer,
  privacy documentation, and both tracker pages.
